# 🧪 School Website QA Testing

## 📌 Project Overview

This repository contains QA documentation for testing a school website.
The goal was to validate core functionality, usability, and identify potential defects.

## 📄 Test Documentation

The following artifacts were created during the testing process:

* **Test Plan** – scope, objectives, testing strategy
* **Checklist** – high-level validation of main features
* **Test Cases** – detailed step-by-step scenarios
